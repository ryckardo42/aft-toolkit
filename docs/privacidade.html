Sync DET — AFT Toolkit

Extensão para Google Chrome e Microsoft Edge

Política de Privacidade

Esta política descreve como a extensão Sync DET — AFT Toolkit coleta, usa e protege os dados durante o seu funcionamento.

A extensão funciona inteiramente na máquina do usuário: ela conversa apenas com o portal do DET, onde o usuário já está autenticado, e com o painel do AFT Toolkit rodando no próprio computador. Não há servidor, serviço em nuvem ou conta remota envolvidos.

Dados coletados

A extensão captura e armazena temporariamente o token de sessão JWT emitido pelo portal do DET (Domicílio Eletrônico Trabalhista) quando o usuário está autenticado. Esse token é obtido a partir dos cabeçalhos das requisições feitas pelo próprio navegador ao domínio auditor-det.sit.trabalho.gov.br.

Esse token é opaco (não é lido nem exibido pela extensão) mas, como todo JWT, carrega internamente identificadores do próprio Auditor-Fiscal autenticado (como matrícula/CIF). A extensão usa apenas a existência desses campos para validar o formato do token — nunca extrai, exibe ou registra esses dados separadamente.

Além disso, o usuário informa voluntariamente o endereço do painel local do AFT Toolkit (por padrão http://127.0.0.1:8347), guardado nas preferências da própria extensão.

Nenhum outro dado é coletado. A extensão não acessa e-mail, localização, histórico de navegação, senhas ou qualquer conteúdo de outros sites.

Como os dados são usados

O token JWT do DET é enviado exclusivamente ao painel local do AFT Toolkit, rodando no próprio computador do usuário (127.0.0.1). O painel usa esse token para consultar a API do DET em nome do próprio usuário e gravar, em pastas locais do computador, as notificações e os documentos a elas vinculados. Esse tráfego não sai da máquina.

O token é armazenado localmente no navegador (chrome.storage.local) e descartado automaticamente após aproximadamente 25 minutos, respeitando o tempo de expiração do próprio token emitido pelo DET.

Os dados baixados do DET ficam sob a guarda do usuário, no sistema de arquivos do seu próprio computador, sujeitos ao sigilo funcional que rege a atividade de inspeção do trabalho.

Compartilhamento de dados

Os dados não são compartilhados com terceiros em nenhuma hipótese e não são usados para publicidade, perfilamento ou análise de crédito. Não há transmissão para servidores do desenvolvedor nem para qualquer serviço em nuvem: toda a comunicação ocorre entre o navegador do usuário, o portal do DET e o painel local na própria máquina.

Segurança

A comunicação com o portal do DET usa HTTPS, como no acesso normal pelo navegador. A comunicação com o painel do AFT Toolkit ocorre apenas dentro da própria máquina do usuário (127.0.0.1/localhost), sem sair para a internet.

Sincronização em nuvem (descontinuada)

Versões anteriores da extensão ofereciam, como alternativa ao painel local, o envio do token para uma instância própria do SisOS na nuvem. Esse modo foi descontinuado na versão 2.1.0: o código de envio para a nuvem foi removido e a operação passou a ser exclusivamente local.
