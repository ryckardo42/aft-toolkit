## 29/08/2026
<!-- commit: lapide-repositorio-publico -->

**Este repositório vai deixar de ser o AFT Toolkit e virar só o caminho de volta para
quem ainda não migrou.** Numa próxima publicação, todo o conteúdo das skills sai daqui —
o toolkit passa a viver inteiramente no pacote versionado do portal `notebooks-aft`.
O que fica neste repositório é só o `README` explicando o que aconteceu e uma versão
enxuta do `/aft-atualizar`, com os poucos scripts de que ele depende (incluindo o
resgate automático das habilidades para quem cair aqui pelo `git pull` de sempre).

O motivo é simples: quem só abrir o Claude Code semanas depois da virada, sem ter feito
a primeira atualização pelo portal, não pode ficar preso com uma instalação morta. Como
a atualização de sempre busca este mesmo repositório, ele continua sendo o caminho que
leva ao cadastro — só que agora conduzindo direto para o portal, em vez de trazer código
antigo que ninguém mais mantém.

Quem já atualizou pelo portal não percebe nada: a mudança aqui é só para o repositório
público, não para a sua instalação.
